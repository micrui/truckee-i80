Excerpts from Caltrans Traffic Census annual Truck AADT tables
(https://dot.ca.gov/programs/traffic-operations/census), I-80 rows for the
Truckee/Donner corridor. "leg" ahead/back = east/west of the count point.
Percentages are Caltrans' classification splits, which the department propagates
from periodic counts; see the source files for estimate-vs-verified coding.
