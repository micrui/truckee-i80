Annual truck traffic series for I-80 at Truckee, 2013-2024, extracted from the
Caltrans Traffic Census "Truck AADT" tables
(https://dot.ca.gov/programs/traffic-operations/census). One row per year,
count point, and leg (back = west of the point, ahead = east). The source_url
column gives the exact file each row came from.

Caveats inherent to the source: Caltrans carries classification splits forward
between periodic counts, so truck percentages repeat across years at a given
point and the truck counts are factored from total volume. The published 2016
file duplicates axle numbers between the 16.285 and 20.225 rows. Treat the
series as the department's official annual estimates, not independent yearly
measurements.
